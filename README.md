# Python-2D-E-Learning-Game
This is an interactive 2D game designed to teach Algebra and Calculus' Differentiation concepts through a fun and engaging learning experience. Developed using Python and several powerful libraries such as Pygame, PyQt5, and SQL, the game offers a dynamic and educational way for students to learn mathematical concepts while playing.
 
## 🛠️ Setup Instructions
 
1. **Import the project into your Python IDE (e.g., PyCharm)**  
   - Open PyCharm.  
   - Select **"Open"** and choose the **`e-learning-game`** folder to import the project.
 
2. **Set up the database using SSMS (SQL Server Management Studio)**  
   - Open SSMS.  
   - Right-click on **Databases** → **Import Data-tier Application**.  
   - Select your `capstones.bacpac` file and follow the wizard to import it.
 
## 🚀 Features
 
### 🎮 For Students:
- **Registration**: Register with a username starting with "TP" (e.g., `TP123`).
- **Login**: Login into the system using your registered username and password.
- **Levels**: Play through 5 levels, each increasing in difficulty. You can only progress to the next level after completing the previous one.
- **In-Game NPC**: An NPC provides explanations and teaches the concepts before each quiz.
- **Quiz**: Answer questions after receiving the explanation. You can click on `?` to get hints during the quiz.
- **Quiz History**: Track your quiz history, review your performance, and see how you improve.
- **Shop**: Purchase items to customize the game or improve your learning experience.
 
### 👨‍🏫 For Lecturers:
- **Login**: Fixed lecturer accounts are provided (login only, no registration).
- **Manage Quizzes**: Lecturers can add, edit, or delete quiz questions.
- **Edit Notes**: Modify NPC lessons and hints for quizzes.
- **Manage Shop Items**: Add or edit items available in the shop for students to purchase.
